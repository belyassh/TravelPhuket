# Таблица заявок (Google Sheets)

Каждая заявка с сайта автоматически попадает в таблицу: одна строка на лист «Заявки» и по строке на каждую позицию на лист «Позиции». Статус выбирается выпадающим списком: `request`, `unpaid`, `paid`, `on hold`, `complete`. Новая заявка получает `request`.

## Установка (10 минут)

1. Создайте таблицу на sheets.google.com, назовите её «Niko заявки».
2. **Расширения → Apps Script**. Удалите содержимое, вставьте код из `sheets/Code.gs`, сохраните.
3. Выберите функцию `setup` и нажмите **Выполнить**. Google попросит доступ (это ваш собственный скрипт). После запуска появятся два листа с шапкой, выпадающим списком статусов и цветами.
4. **Параметры проекта (шестерёнка) → Свойства скрипта → Добавить свойство**: имя `SECRET`, значение любая длинная случайная строка (например, 32 символа). Запомните её.
5. **Развернуть → Новое развёртывание → тип «Веб-приложение»**: «Выполнять от имени: я», «У кого есть доступ: все». Нажмите «Развернуть» и скопируйте **URL веб-приложения** (заканчивается на `/exec`).
6. В Cloudflare, в настройках воркера (Settings → Variables and Secrets), добавьте:
   - `SHEETS_WEBHOOK_URL` (Text): URL из шага 5;
   - `SHEETS_SECRET` (Secret): та же строка, что в `SECRET`.
7. Отправьте тестовую заявку с сайта: строка появится в таблице за несколько секунд.

Если вы меняли код `Code.gs` после развёртывания, нужно **Развернуть → Управление развёртываниями → Изменить → Новая версия**, иначе работает старый код.

## Как работать со статусами

- Кликните по ячейке в колонке «Статус» и выберите значение из списка. Цвет меняется сам.
- Либо выделите одну или несколько строк на листе «Заявки» и выберите в меню **Niko → Статус: …**.
- Колонка «Заметки менеджера» ваша, скрипт её не трогает.

## Что в строке заявки

Дата и время по Пхукету, номер заявки (как в Telegram), статус, имя, телефон, способ связи и ник, отель, список позиций, количество, ближайшая дата поездки, комментарий клиента, источник (UTM).

Повторная отправка той же заявки (например, при обрыве связи) не создаёт дубль: проверка идёт по номеру заявки.

## Безопасность

Адрес веб-приложения публичный, но скрипт принимает только запросы с правильным `SECRET`. Секрет знают только Cloudflare и скрипт. Если он утёк, поменяйте значение в Свойствах скрипта и в Cloudflare.
